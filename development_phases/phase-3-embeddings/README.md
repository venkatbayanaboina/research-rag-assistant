# Phase 3 - Embeddings Fundamentals

## Objective

Learn how text embeddings work and prepare for vector database integration using FAISS.

## What was implemented?

- Generated embeddings using the Sentence Transformers model:
  - all-MiniLM-L6-v2
- Converted text into a numerical vector representation.
- Printed:
  - Embedding dimension
  - Sample embedding values

## Example

Input Text:

text Gradient descent is an optimisation algorithm 

Output:

text Embedding Dimension: 384 First 10 Values: [-0.0717449, 0.02114814, ...] 

## Key Learning

- Embeddings convert text into vectors.
- Similar texts produce similar vectors.
- FAISS stores and searches these vectors.
- All vectors generated by the same model have the same dimension (384).
